# 교실 서랍

초등학교 교사를 위한 웹앱 허브. 검색·즐겨찾기·암호화 개인 링크 보관함과 수업 타이머, 번호 뽑기, 모둠 만들기, 수동 소음 신호등, 질문 카드를 제공합니다.

## 개인정보와 보안
- 허브 수업 도구는 학생 이름·연락처·활동 결과를 수집하거나 서버에 저장하지 않습니다.
- 직접 추가한 링크는 브라우저에서 AES-256-GCM으로 암호화합니다. 비밀번호를 복구할 수 없으므로 암호화 백업을 보관하세요.
- 클라우드 일기장은 현재 구축 중입니다. 별도 Firebase 프로젝트와 Google 로그인, UID별 권한, 암호화 저장을 적용할 예정이며 아직 서비스 중인 기능으로 간주하지 마세요. 기존 로컬 일기는 자동 이전하지 않습니다.
- 공개 저장소에는 일기 기록·사용자 목록·인증 토큰·서비스 계정 키를 포함하지 않습니다. Firebase 웹 앱 설정값은 클라이언트 식별용이며 서버 권한은 보안 규칙으로 제한해야 합니다.
- 브라우저 암호화는 악성 확장 프로그램이나 기기 자체 침해를 막지는 못합니다. 공유 기기에서는 로그아웃하고 화면을 잠그세요.

## 개발
Node.js 24 이상에서 `npm test`, `npm run build`. 허브 자체는 외부 런타임 의존성이 없습니다. `site/`가 GitHub Pages 게시 산출물입니다. 앱 간 경로는 상대 경로를 사용합니다.

## 배포
GitHub Pages용 스크립트는 `dist/`의 정적 파일만 복사합니다. Firebase 규칙은 GitHub Pages와 별도로 해당 Firebase 프로젝트에 배포해야 합니다. `.tools`, `.env`, `.openai`, 로컬 DB, 암호화 백업은 업로드하지 마세요.
